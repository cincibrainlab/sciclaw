Your work visible. Runtime state separate.

Editable settings, profiles, skills, and workspace files live under ~/sciclaw. Credentials, sessions, logs, and transient runtime data live under ~/.sciclaw.

~/sciclaw/ # user-facing
├── config.json
├── profile/
├── skills/
├── templates/
├── backups/
├── addons/
└── workspaces/default/
    ├── memory/
    ├── skills/
    ├── cron/
    ├── irl/
    └── documents and outputs

~/.sciclaw/ # machine-managed
├── auth.json
├── logs/
├── runtime/
├── cache/
├── tmp/
└── workspaces/
    ├── default/ # default workspace runtime
    └── <hash>/  # routed/external runtime

Reproducible by default

Every tool call, every LLM response, every decision is logged with timestamps. Six months from now, you can trace exactly which analysis produced which result.

Portable and auditable

The workspace is plain files — Markdown, JSON, JSONL. No database, no proprietary format. Copy it, git init it, share it with reviewers.

You control the agent

Edit files in ~/sciclaw/profile/ to change behavior, guardrails, identity, and preferences. ~/.picoclaw remains reserved for PicoClaw.
