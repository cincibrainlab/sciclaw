# Documentation layout

This directory is the source for the `sciclaw.dev` GitHub Pages site. Everything
under it is publicly accessible.

- Root HTML, CSS, and site metadata keep the stable public website routes.
- `assets/` contains images, screenshots, and papers used by the site and README.
- `design/` contains RFCs, implementation plans, and technical analyses.
- `drafts/` contains unpublished announcement and correspondence drafts.
- `notes/` contains supporting engineering and workflow notes.
- `ops/` contains operational runbooks and correspondence.
- `releases/` contains archived release announcements.

Keep established website pages at the root unless redirects are provided. Put new
supporting documents in the narrowest matching directory and update references
when moving existing files.
